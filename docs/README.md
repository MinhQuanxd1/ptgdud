# Project Documentation - FashionShop

Thư mục này chứa tài liệu kỹ thuật cho project FashionShop.

## Danh sách tài liệu

| File | Nội dung |
|---|---|
| `ERD_SCHEMA.md` | ERD, schema dữ liệu MongoDB/Mongoose |
| `API_SPEC.md` | API specification dạng Markdown |
| `ARCHITECTURE_DIAGRAM.md` | Diagram kiến trúc tổng thể |
| `sprints/sprint-1.md` | Sprint 1: Setup, UI base, routing, design system, mock data |
| `sprints/sprint-2.md` | Sprint 2: Auth, protected routes, profile |
| `sprints/sprint-3.md` | Sprint 3: CRUD module 1-2, upload |
| `sprints/sprint-4.md` | Sprint 4: CRUD module 3, search/filter/pagination |
| `sprints/sprint-5.md` | Sprint 5: Dashboard, SSR/SSG/ISR, SEO, tối ưu |
| `sprints/sprint-6.md` | Sprint 6: Testing, bugfix, polish UI/UX, CI/CD, docs |

## Công nghệ chính

- Frontend: Next.js App Router, React, TypeScript
- Backend: Express.js REST API
- Database: MongoDB + Mongoose
- Auth: JWT + role admin/user
- Upload: Multer local storage
